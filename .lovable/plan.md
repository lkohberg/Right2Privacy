# Complete Right2Privacy Help Guide

## Goal
Turn the existing question-mark dialog into a complete, ordered guide to the whole app rather than a short encryption explanation.

## Changes
- Organize the guide from first use through everyday messaging: account and identity, adding friends, Contacts, Chat mode, Legacy mode, notifications, Settings, Watchlist, keys and backups, and the privacy model.
- Use clear numbered sections, concise explanations, and a scrollable layout that remains easy to read on phones and computers.
- Keep the current question-mark access points in the desktop sidebar and Settings.
- Add every new guide label and explanation in all 24 supported languages.
- Verify the dialog opens, all sections are reachable, and the page still fits correctly on phone and desktop.

## Technical details
- Expand the existing help dialog component rather than creating a separate page.
- Extend the existing translation records without changing messaging or encryption behavior.
