# Balanced Pro desktop workspace

## Desktop changes

- Replace the thin top navigation with a compact left navigation rail on large screens.
- Present Contacts as a substantial sidebar with larger contact rows, clearer selection, avatars, and reminder counts.
- Add a selected-contact header above the working area so the active conversation is unmistakable.
- Center the encrypt and decrypt tools in a readable workspace instead of stretching them across the page.
- Give the message input and primary action stronger visual weight while preserving every current encryption action and result.

## Responsive scope

- Apply this redesign only on large desktop screens.
- Keep the approved phone and tablet contact flow and floating bottom navigation unchanged.
- Keep Friends and Settings functional with the new desktop navigation rail.

## Technical details

Use the existing semantic colors and controls. The desktop shell becomes a bounded application frame with a narrow global rail; the Contacts page supplies the contact sidebar and focused content pane. No encryption, key delivery, archive, reminder, authentication, or translation behavior changes.
