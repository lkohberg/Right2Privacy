# Clear contact notifications

## Changes
- Add a Clear button in the top-right of each selected contact header on phone, tablet, and desktop.
- Clear only that contact’s pending notification badges and alerts.
- Keep the encrypted key available, so the message can still be decrypted after clearing the notification.
- Disable the action when that contact has no pending notifications.
- Add translated labels and confirmation text for every supported language.

## Verification
- Confirm clearing one contact does not affect another contact.
- Confirm the badge disappears after clearing and decryption still works.
- Check phone, tablet, and desktop layouts.
