# Vertical message mode control

## Build

- Replace the horizontal Encrypt and Decrypt tabs with a compact vertical control beside the message workspace.
- Use a sliding active indicator with lock and unlock icons, clear labels, and large touch targets.
- Animate the message form vertically: Encrypt rolls upward into view and Decrypt rolls downward into view, matching the selected direction.
- Automatically switch to Decrypt when a waiting message is opened, while keeping both modes manually selectable.
- Preserve the current contact selection, encryption, decryption, reminders, and desktop, tablet, and phone layouts.

## Validation

- Check keyboard and touch operation, reduced motion support, and all three screen sizes.
- Confirm switching modes does not clear either form's in-progress content.
